One original line roasting a gadget used every day — the smartwatch that
throws a party every time its wearer stands up, like walking to the fridge
is an Olympic event.

Entry for the [make.fun](https://make.fun) bounty
**One-Line Roast: The Gadget You Use Every Day**
(`u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`).

## How it works

`main.ts` writes the single roast line (99 characters, one line) to
`/output/entry.txt`. No network, no secrets, no dependencies — just Node.

```sh
node main.ts
cat /output/entry.txt
```

## The line

> My smartwatch throws a party every time I stand up, like walking to the fridge is an Olympic event.
